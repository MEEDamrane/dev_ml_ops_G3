# Travaux pratiques

Ce dossier regroupe tous les TP et comptes rendus du groupe.

## Organisation

- `TP1/` à `TP5/` : rendus classés par numéro de TP. Les travaux de Nabila sont placés dans le sous-dossier `Nabila_Rizqy` de chaque TP.
- `TP/` : version complète historique du TP3.
- `tp3/` et `tp4/` : autres rendus séparés déjà présents dans le dépôt.

Les noms et sous-dossiers historiques sont volontairement conservés pour ne pas mélanger ou écraser les travaux des différents membres.
